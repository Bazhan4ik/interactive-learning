Multiplying a vector by a scalar *k* **scales** it. Each component is multiplied by *k*:

*k* (x, y) = (*k*x, *k*y)

What happens depends on *k*:

- *k* > 1 stretches the vector
- 0 < *k* < 1 shrinks it
- *k* < 0 flips it to point the opposite way
- *k* = 0 collapses it to the zero vector

The result always stays on the same line through the origin as **v**. Only the length changes, and possibly which way along the line it points. The new length is the old one times the size of *k*:

|*k* **v**| = |*k*| · |**v**|

Move the slider to change *k*, and drag **v** to try other vectors. Notice that −1 · **v** is exactly the −**b** from the previous section.

Scaling and adding together let you reach any point in the plane from just two vectors that don't lie on the same line. That idea, the **linear combination**, is at the heart of linear algebra.
