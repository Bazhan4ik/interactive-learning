# learn

Interactive learning, generated: describe what you want to learn, and an LLM
writes lessons as code that render into interactive diagrams.

```sh
nvm use        # Node >= 22.17
npm install
npm run dev    # then open http://localhost:5173/dev
npm test
```

- Engine architecture: [`src/lib/engine/README.md`](src/lib/engine/README.md)
- Adding library objects: [`src/lib/library/README.md`](src/lib/library/README.md)
- Writing scenes: [`src/lessons/README.md`](src/lessons/README.md)
